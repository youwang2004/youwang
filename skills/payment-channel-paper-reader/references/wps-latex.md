# 三种 WPS 公式与复制校验

用于精读中的算法转排，以及明确要求 WPS 公式代码的局部任务。目标是复制后仍保留全部数学含义和细小记号，不以好看为由简化算法。

## 自动选型

本技能根据实际待解析的图片／文字选择，不反复让用户确认；用户主动指定方式时优先执行。单独的公式转写聊天若另有“未指定先询问”的约定，仅在那个场景遵守，不把它混入精读默认流程。

| 内容特点 | 选择 | 排版 |
|---|---|---|
| 连续赋值、采样、计算与输出，需要多行但无独立标题分隔的必要 | 方式一：分行公式型 | 左对齐 array，首行接口，下方公式和步骤，无标题横线 |
| 简短 Setup／KeyGen／Sign 接口或少量连续公式，一行能清晰显示 | 方式二：单行紧凑型 | 一个单行表达式，无分行环境 |
| 有清晰标题、if／then／else、循环、返回或需突出执行结构 | 方式三：伪代码型 | 左对齐 array，标题后 hline，正文逐行缩进 |

同一论文可因算法特点混用。原图为多列算法时按算法分成独立块，不复刻无法在 WPS 阅读的宽表。普通单条等式直接给该式，不为了套模板虚构算法接口或输出。长单行在正常字号下不易读时改用方式一；不能仅为统一样式删去分支或改写返回值。

## 一算法一部分

每个算法按“原名与定位 → 它完成的具体任务 → 完整代码 → 参数、输出与逐段解释”组织。用途描述至少说明执行者、所在阶段、处理对象、得到什么及谁在后续如何使用；例如“提取算法用正式签名与对应预签名恢复见证，供条件支付下一阶段使用”，还须核对本文是否确实如此，不能只写“用于提取”。

- 一个算法一个 latex 围栏代码块，不逐公式拆块，不把不同算法放同一块。
- 块内只有纯 LaTeX，不放解释段落、Markdown 列表、出处、展示编号或复制提示。完整原调用、已知输入顺序、条件、循环、返回及算法原有 Output 保留。
- 不添加 $、$$、\(...\)、\[...\]、documentclass、usepackage，也不使用依赖宏包的 algorithm／algorithmic／algorithm2e。
- 不加公式序号、逐行数字、tag、label 或自动编号环境。原文定位在块外给出；不能误删幂、下标、轮次、状态标识、阈值或原算法作为数据处理的数字。
- 精读正文仍有可渲染的数学内容；算法给一份可复制源码，不再生成同算法截图。用户仅要代码时省去长篇讲解；用户另要 WPS 推导源码时按语义行组提供，不把多行推导拆成零散碎片。
- Output 在说明中独立列清返回值、发出消息和本地状态副作用；原式没有某返回值，不为模板完整擅自添上。

## 三种基础模板

以下是模板示例，不是所有论文都使用的构造。填入原文内容，不能照抄参数或分支。

### 方式一

~~~latex
\begin{array}{l}
\mathrm{MulSig}(pp,sk_i,m)\rightarrow(\delta_i,m)\\
\delta_i\leftarrow H_0(m)^{sk_i}\\
\mathrm{Output}\ (\delta_i,m)
\end{array}
~~~

### 方式二

~~~latex
\mathit{BAS.KeyGen}(par):\ x\overset{\$}{\leftarrow}\mathbb{Z}_p,\ sk=x,\ pk=X=xG
~~~

### 方式三

~~~latex
\begin{array}{l}
\mathrm{Adapt}(\widetilde{\sigma},y)\\
\hline
(r,\widetilde{s},K,\pi):=\widetilde{\sigma}\\
s:=\widetilde{s}\cdot y^{-1}\\
\mathbf{return}\ (r,s)
\end{array}
~~~

## 数学细节与美观

- 上横线的作用范围要与原图一致，例如 \overline{\mathrm{PK}}、\overline{\mathrm{SIG}}；\bar{x} 与 \overline{x} 根据原图短标记／整体覆盖选择，不把整体横线变成只覆盖首字母。不能用普通 Unicode 组合横线代替可靠数学命令。
- 帽号、波浪号同样核对覆盖范围，按原图选 \hat{x}／\widehat{x}、\tilde{x}／\widetilde{x}。保留不同对象之间的细微差别，不将 \sigma 与 \widetilde{\sigma} 混为一项。
- 多字符上下标、指数和修饰内容用花括号分组；核对撇号属于哪个对象、逆元和负指数的作用范围，以及 \mathbb、\mathcal、\mathrm、\mathit 等字体承载的含义。
- 随机采样箭头用 \overset{\$}{\leftarrow}，确定性赋值按原文保留 :=、\leftarrow 或等号；蕴含、双向箭头、交互协议的角括号不相互替换。
- 逐项核对乘积／求和的范围、集合／向量索引、空集、成员关系、逻辑连接、模数、严格／非严格不等号及 \perp／\bot 原形。不能为美观删去判断或改变符号。
- 一般使用 array、常用数学命令、明确花括号和 \quad 缩进，避免自定义宏、特殊字形包、复杂跨列嵌套及视觉对齐用的长空格串。
- 标题与正文左对齐，同类赋值保持一致间距；长式在语义边界换行，条件、主体与返回的层级清楚。方式三仅保留标题下的必要横线；不额外画框、着色或增加装饰线。原图有语义颜色时保留；颜色影响 WPS 渲染可先给无色但符号完整的版本。
- 中文长说明放块外。关键词使用简单的 \mathrm 或 \mathbf；保留数学对象原有字体，不把整块公式一律加粗或斜体。

## 复制前后验证

1. **源式逐项比对。** 直接查看原页／清晰图，逐项核对全部修饰、参数、域、阈值和分支，抽取文本不作为唯一依据。源图疑似错字照录，块外指出位置与影响；不可辨认不猜。
2. **源码检查。** 检查花括号、环境闭合、行末换行、修饰范围与反斜杠，避免双重转义、截断和丢行。分开检查数学内容与去除展示编号。
3. **可用渲染器检查。** 在当前可用环境渲染代表性复杂式，目视比对横线、帽号、波浪号、上下标、随机箭头、求积范围与标题横线。若修改模板，至少检查该模板涉及的特性；不为每个简单式另造截图。
4. **目标 WPS 检查。** 可以访问用户 WPS 且已授权操作时，在可逆的测试公式中实际粘贴，检查显示和复制路径，避免覆盖用户正文。用户自己反馈渲染结果时依据反馈修改。不可访问 WPS 就明确仅完成源式／语法或其他渲染器检查，不能承诺已经保证所有 WPS 版本不丢符号。
5. **兼容回退不改数学。** 不兼容命令可以换为含义与修饰范围相同的常用写法；需要拆分超长块时先压缩无关文字、采用分行，并保持一个算法的完整部分。不能通过删除上横线、改成普通字母或把箭头变成减号解决显示问题。无法保持的内容具体报告。
