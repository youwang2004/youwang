# youwang

用于维护可在多台电脑上安装、调用和持续优化的 Codex 技能。

## 支付通道论文精读

技能名称：`payment-channel-paper-reader`；当前版本以 [SKILL.md](skills/payment-channel-paper-reader/SKILL.md) 的 `metadata.version` 为准。

[查看完整技能](skills/payment-channel-paper-reader/SKILL.md)

默认用中文精读区块链支付通道、状态通道和支付通道网络论文，重点输出：

- 参与方、状态、符号与系统假设。
- 谁向谁发送什么、如何签名与验证、何时改变哪一份状态。
- 核心算法逐段讲解，以及基线到本文的实质改造与代价。
- 带稳定步骤编号的成功路径、时序依赖、序列图与异常分支。
- 贯穿示例、资金与时间条件核对、原文位置和未决问题。

严格区分必须先后、有依据的并发、条件分支与未规定顺序；不编造缺失步骤，不把签名、广播、确认或链下记账当成同一事件。

## 在另一台电脑首次安装

在那台电脑的 Codex 新建或打开对话，发送：

```text
请使用 $skill-installer 安装这个 skill：
https://github.com/youwang2004/youwang/tree/main/skills/payment-channel-paper-reader
保留全部参考文件，安装到当前设备的个人 skills 目录，并校验安装结果。
```

如果技能暂未出现，重新打开对话；仍未出现时重启 Codex。

这是各设备的本地安装，登录同一个账号不能替代安装步骤。官方对本地发现目录和仓库安装方式的说明见 [Build skills](https://learn.chatgpt.com/docs/build-skills)。

## 每次读论文

提供论文 PDF、正文或链接后发送：

```text
请用 $payment-channel-paper-reader 精读这篇论文。
重点讲清具体交互、算法执行过程、相对基线如何改造，以及全文交易流程的严格时序。
每一步说明前置条件、消息、校验、状态变化和失败去向，并给原文定位。
```

只需追踪局部时，也可以说“只讲算法 2 怎么接入交易流程”或“只重建失败退款的先后顺序”。

## 优化与更新

只想调整本次讲解，可以继续追问，不必修改 skill。希望以后所有论文都遵守时，在任意对话发送：

```text
更新论文精读 skill：请把本次对话中已经明确、需要长期保留的阅读要求
合并到 https://github.com/youwang2004/youwang 的最新版
skills/payment-channel-paper-reader 中，并更新当前设备。
先读取仓库最新内容，保留其他对话已加入的规则，避免用旧版本覆盖。
完成后告诉我新增了哪些规则、新版本，以及是否已成功同步到 GitHub。
```

也可在该指令后指定一条新要求，或在一篇论文读完后汇总本次的多条改进。模型应依据技能内的优化规则归纳、去重、处理冲突、更新版本并回写本仓库；不能仅回复“记住了”。

每次更新都以仓库最新版本为基础；提交前若发现别的对话已经更新，重新读取并合并，再尝试非强制提交。版本历史保留在仓库提交记录中。只有实际保存和推送成功的要求，才进入各设备可获取的统一版本；没有写入的聊天反馈不自动汇总。

新对话想先用上累计改进，可发送“先同步论文精读 skill 的仓库最新版，再用它读这篇论文”。正在进行的其他对话也需重新同步才会使用新规则。

另一台电脑获取最新版本时发送：

```text
请从 https://github.com/youwang2004/youwang 的 main 分支同步
skills/payment-channel-paper-reader 到这台电脑的个人 skills 目录。
先比较版本和本地尚未上传的改动，必要时合并，不要直接丢弃本地优化。
保留所有参考文件，校验结果并说明实际安装的版本。
```

已存在的技能需要比较和更新；不要把安装器因目录存在而退出当作更新成功。各电脑需要实际拉取或导入新版本，本仓库本身不会自动为所有电脑安装或更新。

完整说明见 [跨设备使用](skills/payment-channel-paper-reader/references/distribution.md)。
