# youwang · 论文精读技能

这里维护可在多台电脑上安装、持续合并阅读反馈的 Codex 技能。当前核心技能是 [payment-channel-paper-reader](skills/payment-channel-paper-reader/SKILL.md)，用于区块链支付通道、状态通道和支付通道网络论文。

最新版本以 [SKILL.md 的 metadata.version](skills/payment-channel-paper-reader/SKILL.md) 为准；具体修改可查看仓库提交记录。

## 怎样读一篇论文

精读以论文实际章节为主线，默认中文讲解，保留英文术语、算法原名和数学符号。可以阅读全文，也可以只追踪一个算法、局部交互或失败路径。

| 内容 | 默认处理方式 |
|---|---|
| 摘要 | 完整翻译，保留条件、结果与限定语 |
| 所有纳入范围的正文 | 保留到最深的小节与段首编号项，逐段译读并从原文反查译文落点。难点、公式、算法和图表就近讲解 |
| 引言与背景 | 用同一场景走一遍原有办法，指出哪个条件改变、谁在哪一步受限、本文怎样处理。拓扑、费用、可见性或状态的对照紧邻对应段落 |
| 模型与预备知识 | 说明角色、通道、假设、符号与输入来源，补足理解当前构造所需的基础 |
| 方法与算法 | 章前列参数、公式与调用。原文或附录给出构造的多步算法，各自重排算法框，解释每步生成、验证和输出。 |
| 支付过程 | 《前因后果》分阶段画出各参与方的计算、收发、验算和存档。《全文精读》篇末按相同步号给出同一执行的公式和伪代码。 |
| 安全内容 | 还原对手、假设和主张，按触发分段讲理想功能，形式化证明依阅读范围展开，完整解释实际支付中的验签、证明、共识及授权 |
| 性能／实验 | 完整翻译实验文字与图表说明，嵌入原图原表，用一两句话读出条件与结果 |
| 结论与反思 | 区分原文结论和扩展思考，讨论具体机制、设计取舍及可借鉴的研究问题 |

正文保留原章节、算法名及节、式、图表的交叉引用。专业名词首次给英文原名和职责，译名不统一时保留英文。在独立的《前因后果》中用同一实例画出必要的准备、支付和结算；关键验证写清由谁执行、核对什么、通过后哪份状态生效，以及原文规定的失败去向。

### 两份成稿和已读论文库

[打开按任务编排的详细提示词](skills/payment-channel-paper-reader/references/authoring-prompts.md)

- `<论文>_全文精读.md` 保留原章节译文、就地解释、章内算法框和原图。篇末列同一实例的完整交易算法推演，并集中整理参考文献、原编号和 CCF 索引。两份正文用作者、方案名或有核实的原始出处定位。
- `<论文>_前因后果.md` 沿同一场景讲需求、旧办法的断点、设计贡献和条件，另设「完整交易交互」逐阶段演算。读者从本文件链接到《全文精读》查篇末书目。详见[配套稿提示词](skills/payment-channel-paper-reader/references/causal-narrative.md)。
- 交付两份成稿后，提醒读者审核成稿、候选代表原图和交互图。确认后按论文整理到本机 `library/`，通过 `library/已读论文.md` 打开原文入口、两份稿和各阶段图。复读修改也先审核。已配置私有仓库时，同步获准版本，其他设备可用有权限的账号查看。 [归档规范](skills/payment-channel-paper-reader/references/reading-library.md)

## 讲解深度持续保留，呈现随论文调整

完整算法、参数来源、逐步推导、真实消息与接收检查、状态／资金／秘密变化、阶段出口和图文解释是稳定要求。读者应能沿同一笔付款重放协议；转抄公式、罗列接口或只给总览不能代替精读。正常显示公式而不附源码，不减少这些内容。

章节组织、背景与大致流程可以依论文调整。完整交易的阶段、角色和动作按论文落实，各阶段用统一实参连接计算、消息、验证及存档。

## 公式：直接正常展示

精读直接显示公式和算法。原文把多个有构造的子程序混写在一起时，按依赖拆成独立框，每框首行给调用式并保留条件、计算与返回。正常字号下优先一行，确需换行时按参数或运算项续行。单独的 WPS 转写按用户选定格式。

先核对原文及必要的显示效果；普通公式显示正常时，不额外安装渲染依赖、搭建测试网页或批量截图。出现乱码、溢出或实际渲染错误时再定向检查。

## 完整交易交互图

完整实例使用 Accio 图 2 的角色分栏和 BlindHub 完整版图 29 的演算深度。每张图首重列本阶段参与方及身份，步骤号跨图接续。三方及以上分别交代每人的实际动作。角色栏写本次调用、逐项代入、验算、保存和输出，箭头标实际消息。原例已有数值就代入，其余用原符号及约束。篇末公式稿沿用同一组实参与步骤。

普通字号能容纳的公式、算法调用和消息元组保持一行。可利用相邻留白或略偏出栏中心，保持操作归属与收发端点清楚。作者原图保留原色，背景和大致流程按本篇图例选用角色、颜色和线型。详见[分阶段交互图](skills/payment-channel-paper-reader/references/protocol-flow-diagrams.md#分阶段交互图)。

## 开始使用

提供论文 PDF、正文或链接后发送：

~~~text
请用 $payment-channel-paper-reader 精读这篇论文，按章节完整译读。请在《前因后果》画完整交易，在《全文精读》篇末沿同一步骤写算法推演，交付两份 Markdown 后，提醒我审核成稿和准备入库的图，确认后再归档。
~~~

只想看局部时，可以直接限定范围。需要按原图带着例子讲，可以这样说。

~~~text
请用 $payment-channel-paper-reader，只讲这部分的交互。沿作者例子按实际阶段出图，在各角色栏写本地计算、发送的参数、接收后的验证和状态变化。
~~~

全文先在聊天中按章节展示图文讲解，核心图紧邻解释；完成后交付两份相互链接的本地 UTF-8 Markdown，不能只发链接和简短总结。局部请求只处理相关部分。图按需嵌入，不自动附 PDF、压缩包或多套源码。阅读笔记、论文图和个人材料不会因为允许同步技能规则就被公开上传。

## 安装到另一台电脑

在目标电脑的 Codex 中发送：

~~~text
请使用 $skill-installer 安装这个 skill：
https://github.com/youwang2004/youwang/tree/main/skills/payment-channel-paper-reader
保留全部参考文件，安装到当前设备的个人 skills 目录，并校验安装结果。
~~~

若技能尚未显示，重新打开对话后核对。已存在同名技能时按更新处理，先比较版本和本地差异，不能直接清空或把重复安装失败当作成功。

## 同步与持续优化

让当前设备先获取仓库累计改进：

~~~text
请从 https://github.com/youwang2004/youwang 的 main 分支同步
skills/payment-channel-paper-reader 到本机个人 skills 目录。
先比较版本和未同步的本地改动，必要时合并，保留全部参考文件。
校验后说明实际安装版本，再用新版精读论文。
~~~

只想纠正本篇内容，直接追问即可。需要把反馈长期保留时发送：

~~~text
请更新论文精读 skill。把本次确认的长期要求合并到 youwang2004/youwang 的 main 分支，
更新 skills/payment-channel-paper-reader，保留已有规则，并同步当前设备。
README 的说明或调用示例受影响时一并更新。请报告改动、版本、校验和 GitHub 同步结果。
~~~

更新以仓库最新版本为基础，合并有效本地差异。发布时检查 README，涉及使用说明或调用方式时一并更新。提交时避免覆盖其他对话的新改动，完成后分别核实 GitHub 与本机。各电脑仍需实际同步，正在进行的其他对话需重新加载新版，登录同一账号不代表自动安装或同步。

技能和个人库分别同步。公共仓库维护技能规则，个人论文材料通过已配置的私有仓库同步。更新技能时保留本机 `library/`。

更多维护细节见 [跨设备使用](skills/payment-channel-paper-reader/references/distribution.md) 与 [反馈与优化](skills/payment-channel-paper-reader/references/evolution.md)。
